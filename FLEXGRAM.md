# FlexGram (локальный прототип)

FlexGram добавлен в официальный репозиторий Telegram iOS как отдельный Bazel-модуль //submodules/FlexGram:FlexGram и открывается из **Настройки → Флекс · FlexGram**.

Основа — официальный репозиторий TelegramMessenger/Telegram-iOS, commit 24638bc69bd083981b178dd1e7f921eebbf7fc46.

В локальном прототипе есть:

- виртуальные счётчики Stars и TON с кнопками изменения;
- локальный конструктор подарка с выбором предмета, фона и узора;
- локальная замена имени в собственном профиле и имени автора в поддерживаемых подписях сообщений;
- сохранение переопределений, виртуальных балансов и списка подарков в UserDefaults и JSON.
- локальный ник и аватар выбранного собеседника через его профиль; ник подставляется в заголовок чата, список чатов, профиль и подпись автора в поддерживаемых сообщениях;
- локальная замена текста выбранного текстового сообщения через меню долгого нажатия;
- подарки выбранному собеседнику за 100 виртуальных Stars, отображаемые в разделе его профиля на этом устройстве.

Экран не использует Telegram API для чтения или записи виртуальных значений. Переопределения профиля, аватара и сообщения применяются только при отображении на этом устройстве; они не меняют серверный профиль, текст или атрибуты сообщений. Локально добавленный подарок не приходит собеседнику и не появляется у него в официальном Telegram. Реальных платежей и кошелька нет. После изменения профиля или сообщения откройте его заново для обновления отображения. Скриншоты Leadgram не были приложены к исходной переписке, поэтому оформление пока основано на её текстовом описании.

## macOS CI и Sideloadly

Workflow .github/workflows/flexgram-unsigned-ipa.yml запускается после push в ветку flexgram или вручную на GitHub Actions macOS с Xcode 27.1. Перед первым запуском:

1. Создайте собственные API ID и API hash Telegram и подготовьте конфигурацию на основе build-system/template_minimal_development_configuration.json с собственным bundle_id, api_id и api_hash. Для CI сборки team_id можно не указывать: workflow подставляет временный синтетический ID, а Sideloadly подпишет IPA вашим Apple ID.
2. Сохраните весь JSON конфигурации в секрете репозитория GitHub FLEXGRAM_CONFIGURATION_JSON.
3. Запустите workflow вручную. Он собирает arm64 IPA с временным локальным профилем и сохраняет артефакт FlexGram-unsigned-ipa на 7 дней. В этой CI сборке расширения Telegram отключены.
4. Скачанный IPA можно передать Sideloadly для повторной подписи вашим Apple ID. Сам workflow не подписывает IPA вашим сертификатом и не публикует его.

Upstream сейчас закрепляет Xcode 27.1, Bazel 9.2.0 и macOS 27 в versions.json; используйте runner с меткой xcode-27. Новые локальные функции ещё не прошли сборку и проверку на iPhone. Подписанного IPA здесь нет.

Перед распространением необходимо соблюдать условия README официального Telegram iOS: использовать собственное имя приложения/API credentials, не выдавать клиент за официальный Telegram и публиковать исходный код в соответствии с лицензией upstream.
