# FlexGram (локальный клиент)

VisualGram добавлен в официальный репозиторий Telegram iOS: локальные данные находятся в модуле `//submodules/FlexGram:FlexGram`, экраны и отображение подарков — в `//submodules/FlexGramUI:FlexGramUI`. Он открывается из **Настройки → VisualGram · локальный вид** или тремя быстрыми нажатиями на вкладку **Чаты** (пауза между нажатиями не больше секунды). Активации и отдельного сервера нет.

Основа — официальный репозиторий TelegramMessenger/Telegram-iOS, commit 24638bc69bd083981b178dd1e7f921eebbf7fc46 (13.2). Для приложения задано отображаемое имя Telegram и отдельная иконка с буквой F. Это неофициальный клиент.

Для применения отдельного файла `VisualGram-Telegram-13.2.patch` нужен чистый checkout указанного commit официального Telegram iOS. Проверьте патч командой `git apply --check VisualGram-Telegram-13.2.patch`, затем примените `git apply VisualGram-Telegram-13.2.patch`. Патч содержит только изменения исходников; IPA создаётся отдельной сборкой на macOS.

В локальном прототипе есть:

- виртуальные счётчики Stars, TON и GRAM с кнопками изменения, вводом точной суммы и локальной историей операций;
- локальная карта баланса, которую можно украсить изображением одного из подарков собственного профиля и настроить положение и размер изображения;
- до 40 доступных обычных Star Gifts из каталога Telegram со штатным отображением, вариантами модели, фона и узора; состав списка зависит от каталога аккаунта;
- локальная замена имени в собственном профиле и имени автора в поддерживаемых подписях сообщений;
- сохранение переопределений, виртуальных балансов и списка подарков в UserDefaults и JSON.
- локальный ник и аватар выбранного собеседника через его профиль; ник подставляется в заголовок чата, список чатов, профиль и подпись автора в поддерживаемых сообщениях;
- локальные поля «О себе», приветствия, времени работы и адреса, которые показываются в профиле как локальные данные;
- отдельные списки локальных имён и подарков: имя выбирается нажатием, удаляется свайпом; подарок можно удалить свайпом или продать за виртуальные Stars;
- локальный значок чата и переключатель общего вида имён, аватаров, значков и подарков между аккаунтами на одном устройстве;
- локальная замена текста выбранного текстового сообщения через меню долгого нажатия;
- локальные копии подарков выбранному собеседнику за 100 виртуальных Stars; они отображаются изображениями в разделе профиля на этом устройстве.
- локальное оформление выбранного подарка моделью, узором и фоном из каталога Telegram. Это визуальное изменение, которое не создаёт настоящий NFT.
- локальная передача подарка из своего профиля в профиль собеседника с комиссией 25 виртуальных Stars и записью в историю баланса. Собеседник не получает этот подарок через Telegram.
- локальная продажа собственного подарка за 75 виртуальных Stars с удалением локальной копии и записью в историю.
- планирование локального подарка с выбором секунды и отменой до появления в профиле. Стоимость резервируется при планировании и возвращается при отмене. Пока приложение активно, локальная доставка проверяется каждую секунду; если оно закрыто, подарок появляется при следующем запуске. Сервер Telegram его не доставляет.

FlexGram читает каталог подарков и медиа через Telegram API, поэтому для отображения изображений нужно соединение или уже имеющийся кэш Telegram. Локально сохраняются записи подарков и ссылки на медиа, а не отдельные офлайн-файлы изображений NFT. Уникальные NFT не выдаются сервером и другим людям не отправляются. Виртуальные значения и локальные подарки в Telegram не отправляются. Переопределения профиля, аватара и сообщения применяются только при отображении на этом устройстве; они не меняют серверный профиль, текст или атрибуты сообщений. Локально добавленный подарок не приходит собеседнику и не появляется у него в официальном Telegram. Реальных платежей и кошелька нет. После изменения профиля или сообщения откройте его заново для обновления отображения.

При установке через Sideloadly общий контейнер App Groups может быть недоступен после переподписи. FlexGram теперь использует личное постоянное хранилище приложения в таком случае; расширения в CI-сборке отключены.

## macOS CI и Sideloadly

Workflow .github/workflows/flexgram-unsigned-ipa.yml запускается после push в ветку flexgram или вручную на GitHub Actions macOS с Xcode 27.1. Перед первым запуском:

1. Создайте собственные API ID и API hash Telegram и подготовьте конфигурацию на основе build-system/template_minimal_development_configuration.json с собственным bundle_id, api_id и api_hash. Для CI сборки team_id можно не указывать: workflow подставляет временный синтетический ID, а Sideloadly подпишет IPA вашим Apple ID.
2. Сохраните весь JSON конфигурации в секрете репозитория GitHub FLEXGRAM_CONFIGURATION_JSON.
3. Запустите workflow вручную. Он собирает arm64 IPA с временным локальным профилем и сохраняет артефакт FlexGram-unsigned-ipa на 7 дней. В этой CI сборке расширения Telegram отключены.
4. Скачанный IPA можно передать Sideloadly для повторной подписи вашим Apple ID. Сам workflow не подписывает IPA вашим сертификатом и не публикует его.

Upstream сейчас закрепляет Xcode 27.1, Bazel 9.2.0 и macOS 27 в versions.json; используйте runner с меткой xcode-27. Сборка #14 с исправленным хранилищем запустилась на iPhone и позволила войти в аккаунт. Обновлённые экраны и отображение подарков требуют отдельной сборки и проверки на устройстве.

По просьбе владельца репозитория текущие изменения готовятся только как исходный патч: новый запуск CI не выполняется. Новые функции ещё не проверены сборкой и не входят в ранее выпущенные IPA.

Перед распространением необходимо соблюдать условия README официального Telegram iOS: использовать собственные API credentials, ясно указывать, что это неофициальный клиент с отдельной иконкой, и публиковать исходный код в соответствии с лицензией upstream.
